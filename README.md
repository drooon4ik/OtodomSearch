# Otodom Investment Search — Warsaw

Инструмент для поиска и оценки инвестиционных квартир в Варшаве у станций метро.

## Flow

```
config.py → metro_url.py → scraper.py → data/listings.json
                                                │
                         fetch_poi.py →         ▼
                         data/poi.json → enrich.py → data/enriched.json
                                                │
                                                ▼
                                           score.py → data/scored.csv
                                                │
                                                ▼
                                          tracker.py → data/snapshots/
```

## Инвестиционная цель

- Купить на собственные ~480 000 zł + ипотека
- Сначала жить самому, потом сдавать или перепродать
- Площадь 35–60 м², только метро M1/M2, ≤ 30 мин до центра

## Использование

```bash
pip install -r requirements.txt
python3 -m playwright install chromium

python3 scraper.py          # собрать объявления (все страницы)
python3 scraper.py --pages=3  # тест на 3 страницах

python3 enrich.py           # обогатить новые (пропускает уже обработанные)
python3 enrich.py --limit=50

python3 fetch_poi.py        # загрузить инфраструктуру OSM (один раз)

python3 score.py            # пересчитать скоры → data/scored.csv

python3 tracker.py          # отчёт об изменениях с прошлого прогона
```

`enrich.py` автоматически вызывает `tracker.py` в конце и показывает что появилось, ушло или изменилось в цене.

## Конфигурация (`config.py`)

| Параметр | Значение |
|---|---|
| Станции метро | 28 станций M1+M2, проверены Google Directions API |
| Радиус полигона | 900 м от каждой станции |
| Площадь | 35–60 м² |
| Год постройки | от 1950 |
| Материалы стен | кирпич, пустотелый блок, силикат, железобетон |
| Стоимость ремонта | `do zamieszkania` 500 / `do wykończenia` 3150 / `do remontu` 4150 zł/м² |

### Веса скоринга

| Фактор | Вес | Примечание |
|---|---|---|
| Эффективная цена/м² | 0.40 | логарифмическая нормализация — сильнее штрафует дорогие |
| Близость к инфраструктуре | 0.25 | супермаркет×0.4 + школа×0.35 + университет×0.25 |
| Год постройки | 0.15 | |
| Расстояние до центра | 0.15 | мягкий штраф — все квартиры у метро |
| Этаж | 0.05 | штраф за партер, последний этаж и 1-й этаж |

## Структура проекта

```
├── config.py        # все параметры
├── scraper.py       # парсер Otodom
├── enrich.py        # обогащение деталями + вызов tracker
├── fetch_poi.py     # инфраструктура из OpenStreetMap
├── metro_url.py     # генерация URL с полигоном
├── score.py         # инвестиционный скоринг
├── tracker.py       # отслеживание изменений между прогонами
├── .env             # GOOGLE_API_KEY (не в git)
└── data/            # генерируемые файлы (не в git)
    ├── listings.json
    ├── enriched.json
    ├── scored.json / scored.csv
    ├── poi.json
    └── snapshots/
```

## Технические особенности Otodom

- Полигон работает **только** в `viewType=map` — в режиме листинга игнорируется
- Виртуальный список рендерится при скролле (`headless=False`), данные уже в DOM — сетевых запросов при скролле нет
- Пагинация через `goto(url + &page=N)`, максимум 36 объявлений на странице
