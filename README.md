# Otodom Investment Search — Warsaw

Инструмент для поиска и оценки инвестиционных квартир в Варшаве у станций метро.

## Flow

```
config.py → metro_url.py → scraper.py → data/listings.json
                                                │
                         fetch_poi.py →         ▼
                         data/poi.json → enrich.py → data/enriched.json
                                                │
                                                ▼
                                           score.py → data/scored.csv
                                                │
                                                ▼
                                          tracker.py → data/snapshots/
```

## Инвестиционная цель

- Жить самому, потом сдавать или перепродать
- Площадь 35–60 м², только метро M1/M2, ≤ 30 мин до центра
- Горизонт 10+ лет, приоритет — прирост стоимости

## Использование

```bash
pip install -r requirements.txt
python3 -m playwright install chromium

python3 scraper.py                    # собрать объявления (все страницы)
python3 scraper.py --pages=3          # тест на 3 страницах

python3 enrich.py                     # обогатить новые + перезапросить без features/description

python3 fetch_poi.py                  # загрузить инфраструктуру OSM (один раз)

python3 score.py                      # пересчитать скоры → data/scored.csv

python3 tracker.py                    # отчёт об изменениях с прошлого прогона
```

`enrich.py` автоматически вызывает `tracker.py` в конце.

## Веса скоринга

| Фактор | Вес | Примечание |
|---|---|---|
| Эффективная цена/м² | 0.40 | логарифмическая нормализация — сильнее штрафует дорогие |
| Этаж | 0.10 | партер 0.3 / 1-й 0.5 / последний 0.4 / остальные 1.0 |
| Год постройки | 0.10 | плато 1.0 для 2010–2020, плавный спад к старым и строящимся |
| Расстояние до центра | 0.08 | слабый сигнал — все квартиры у метро |
| Район | 0.08 | качество жизни: Śródmieście 1.0 / Mokotów 0.90 / Wola 0.85 / Praga 0.65 |
| Бонусы из объявления | 0.08 | балкон, терраса, двусторонняя, тихий двор, кладовка, кондиционер |
| Близость к инфраструктуре | 0.06 | супермаркет×0.45 + университет×0.35 + школа×0.20 |
| Материал стен | 0.05 | кирпич 1.0 / силикат 0.8 / железобетон 0.7 / pustak 0.6 |
| Тип рынка | 0.05 | вторичный 1.0 / первичный 0.6 |

### Бонусы из объявления (`s_desc`)

Из структурированного поля `features` (Otodom API):
балкон (0.30), терраса (0.35), лоджия (0.20), кладовка (0.20), кондиционер (0.20).

Из текста описания: **двусторонняя** (0.25), тихий двор (0.20).

## Структура проекта

```
├── config.py        # все параметры и веса
├── scraper.py       # парсер Otodom (Playwright)
├── enrich.py        # обогащение деталями + features + description
├── fetch_poi.py     # инфраструктура из OpenStreetMap
├── metro_url.py     # генерация URL с полигоном
├── score.py         # инвестиционный скоринг
├── tracker.py       # отслеживание изменений между прогонами
├── .env             # GOOGLE_API_KEY (не в git)
└── data/            # генерируемые файлы (не в git)
    ├── listings.json
    ├── enriched.json
    ├── scored.json / scored.csv
    ├── poi.json
    └── snapshots/
```

## Технические особенности Otodom

- Полигон работает **только** в `viewType=map` — в режиме листинга игнорируется
- Виртуальный список рендерится при скролле (`headless=False`), данные уже в DOM
- Пагинация через `goto(url + &page=N)`, максимум 36 объявлений на странице
- `features` (балкон, лифт и др.) живут в `ad.features[]`, не в `characteristics`
